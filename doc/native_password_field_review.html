Non-goals

Credential UX stays outside this artifact

This companion lane intentionally avoids states that would imply Rails Fields Kit owns security policy or authentication product decisions.

  • No password visibility toggle or reveal button.
  • No strength meter, generated password flow, or credential storage guidance.
  • No authentication workflow, reset flow, or account policy copy.
  • No runtime Ruby / JavaScript behavior or production CSS changes.
Review prompts

Desktop and narrow viewport checks

  • At desktop width, confirm label, required marker, hint, error, masked value, and `autocomplete` cue can be scanned without treating the cue as policy guidance.
  • At 390px to 460px width, confirm prefix and suffix wrap above or below the masked input without hiding the field value, hint, or error copy.
  • Confirm the page reads as a password wrapper visual lane and not as a proposal for visibility toggles, strength meters, credential policy, or authentication workflow.
