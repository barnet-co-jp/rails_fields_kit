Events versus contract reader

  • events Use forwarded interaction events when host app code must react as selection changes.
  • contract reader Use `tomSelectSelectionContract(element)` when QA scripts or integration code need to inspect the current rendered state on demand.
  • The helper does not expose the Tom Select instance, selected item DOM, option metadata, validation UI, request lifecycle, or mutation API.
  • This visual reference is stacked on the `tomSelectSelectionContract(element)` public API branch; keep final wording aligned with that helper's values-only contract before landing.

This page is a static documentation artifact. It does not change production helper markup, runtime JavaScript, event payloads, selected preload behavior, or visible selected-item UI.
