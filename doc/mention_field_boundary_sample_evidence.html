Boundary comparison

The proposal lane stays useful only while it does not promote a helper that has not landed.

Lane Use when Boundary
rfk_text_area plus host overlay The app stores ordinary prose and wants inline `@user` or `#tag` affordances. Rails Fields Kit may render the textarea wrapper, but parsing, overlay UI, hidden metadata, persisted links, and notifications stay host-owned.
rfk_autocomplete The entire field value is a suggestion-backed text value. Not an inline mention parser; it should not imply entity-link persistence inside longer prose.
rfk_token_search The field stores query syntax such as `status:open owner:haru`. Host app owns search execution and result semantics; this is not textarea mention replacement.
rfk_tags The field stores multiple selected values or tags. Use for tag editor fields, not for tags embedded inside arbitrary textarea prose.
