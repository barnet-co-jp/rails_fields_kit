Slug helper boundary evidence

This page gives reviewers a visual lane for the current slug boundary: Rails Fields Kit renders ordinary native text wrappers, while the host app owns slug generation, preview, validation, locking, and persistence.

Rails Fields Kit owns today

  • Native helper wrapper rendering through existing helpers such as rfk_text_field
  • Label, hint, error, affix, and accessibility wiring for ordinary inputs
  • Documentation that keeps proposal-only slug helpers out of current public API

Host app owns today

  • Slug generation, normalization, transliteration, and reserved-word rules
  • Uniqueness checks, validation copy, lock/regenerate controls, and persistence
  • Any JavaScript that connects a title input to a slug preview or slug field
