Reviewer routing

Pick the lane by responsibility, not by helper name alone.

Surface Use when Boundary
rfk_select native wrapper The app needs a normal browser select with Rails Fields Kit label, hint, error, required marker, and generated-id wiring. No search, async loading, custom renderer, chip UI, or endpoint behavior is implied.
rfk_grouped_select native wrapper The app needs server-rendered optgroup headings and native browser selection behavior. Optgroup labels are reviewable copy; remote grouped options, authorization, and query execution are not Rails Fields Kit-owned.
Tom Select core reference The review needs selected items, active dropdown options, search, preload restore, remote failure, tags, token search, or create states. Use the landed Tom Select visual reference instead of stretching native select evidence into a remote workflow.
