Responsibility boundary

Class configuration is not CSS framework support

Use this lane to check whether the current docs make wrapper class ownership clear before adding production CSS, framework-specific behavior, or helper markup changes.

Rails Fields Kit owns Generated wrapper pieces and the configured class names appended to them.
Host app owns CSS framework availability, spacing scale, colors, validation copy, and layout integration.
Out of scope Bootstrap/Tailwind support, production stylesheet changes, wrapper markup redesign, and configuration API changes.

Use `doc/configuration.md` as the source of truth for initializer keys and override precedence. This static page only visualizes the class-pass-through boundary for design review. When checking the narrow lane, record the viewport and whether long labels, affixes, hints, and error text remain readable without treating this artifact as bundled CSS support.
