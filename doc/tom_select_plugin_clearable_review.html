Plugin and Clearable State Review

Static review lane for distinguishing explicit field-level clear affordances, app-wide default_allow_clear inheritance, and per-item remove buttons. It is a documentation artifact only; Rails Fields Kit does not own Tom Select plugin assets, plugin behavior, or production styling policy.

Scope boundary

What this artifact checks

  • Whole-field clear, inherited default_allow_clear, field-level suppression, and per-item remove affordances are visually distinct at desktop and narrow widths.
  • Long selected labels and long tags wrap inside the control instead of forcing horizontal overflow.
  • Plugin assets, styling, event payloads, selection mutation, and Tom Select lifecycle behavior remain host-app or Tom Select responsibilities.
  • Current package-root helper names are not copied here; use public_api.md#javascript-exports as the source of truth.
Review prompts

Desktop and narrow viewport checks

  • At desktop width, compare explicit allow_clear: true, inherited default_allow_clear, and multi-item remove buttons without reading them as the same action.
  • At 390px-equivalent width, confirm long tag text, long selected labels, hint copy, and clear/remove controls remain reachable without overlapping labels or validation-adjacent copy.
  • Confirm the artifact reads as a static design review lane, not a proposal for Rails Fields Kit to ship plugin styles or clear-event behavior.
