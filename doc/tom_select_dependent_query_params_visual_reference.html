Effective change sequence

Stale cached options are cleared before the hook is dispatched

The sequence is documentation-only; this page does not run a controller or observe network timing.

  1. Abort the in-flight remote search.
  2. Clear cached remote options.
  3. Clear selection only when explicitly enabled.
  4. Ask an open dropdown to reload its current query.
  5. Dispatch rails-fields-kit--tom-select:dependency-change.
Unchanged effective paramsAn input or change notification that leaves effective params unchanged does not dispatch the event.
