Suggested Review Flow

Keep the artifact review small and evidence-driven so it does not drift into implementation or proposal review.

  1. Choose the reviewer task, helper family, lane, or release gate that matches the current PR or design question.
  2. For focused companion or map-only evidence lanes, open visual_references.md before adding another card to this one-screen index.
  3. For package-root contract readers, confirm the current public export and boundary in public_api.md before opening a visual lane.
  4. Open the individual static HTML reference and compare desktop and narrow viewport readability.
  5. Record release or PR evidence in sample_app_results.md when the artifact changes or gates a release.

Scope note. This page is a static index for documentation artifacts. It does not define public helper behavior, JavaScript exports, request lifecycle events, setup diagnostics, or runtime rendering contracts. Use visual_references.md as the maintained source-of-truth map for focused companion and map-only evidence lanes, and use public_api.md#javascript-exports before treating a contract reader as current public API.
