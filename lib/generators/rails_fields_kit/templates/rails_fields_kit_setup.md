# Rails Fields Kit setup

Generated by `rails generate rails_fields_kit:install`. Use as a quick checklist for wiring Rails Fields Kit into this app.

## Setup checklist

- [ ] Run `rails rails_fields_kit:doctor` to check detectable setup state.
- [ ] Confirm `config/initializers/rails_fields_kit.rb` matches this app's needs.
- [ ] Install Tom Select: `yarn add tom-select` (or npm/pnpm).
- [ ] Register the Stimulus controller on this app's Stimulus application:
  ```js
  import { TomSelectController } from "rails_fields_kit"
  application.register("rails-fields-kit--tom-select", TomSelectController)
  ```
- [ ] Load Tom Select CSS: `import "tom-select/dist/css/tom-select.css"`
- [ ] Render a first `rfk_select` field with a server-rendered collection.
- [ ] If using importmap: run `rails generate rails_fields_kit:install --importmap` or add pins manually.
- [ ] If using Vite/bundler: add resolve aliases for `rails_fields_kit` (see README).
