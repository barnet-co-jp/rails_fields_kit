Precedence and ownership
  • Field-level options are the narrowest override and should be used when one field needs distinct visible feedback.
  • Initializer defaults keep repeated fields consistent across the host app.
  • Bundled fallback copy is only the last visible baseline; business-specific help, retry, and validation copy remain host-app responsibility.

This page is a visual reference only. It does not change locale selection, text resolution, request lifecycle, or Tom Select runtime behavior.
