Responsibility boundary

Rails Fields Kit owns

  • Native wrapper structure, labels, hints, errors, affixes, and accessibility wiring.
  • Pass-through of ordinary native attributes and host app data hooks.
  • Documentation that rfk_masked_field is not current public API.

Host app owns

  • Masking library choice, controller behavior, and browser event handling.
  • Locale-specific phone, money, and percent formatting rules.
  • Server-side validation, submitted value normalization, and persistence policy.

Narrow viewport check: labels, hints, error copy, metadata chips, and host-owned data hooks should wrap without making mask behavior look built in.
