Credential-specific features are outside the helper

This comparison makes the absence of built-in password UX explicit so reviewers do not infer hidden behavior from the native wrapper.

Included Native `type="password"` input. Wrapper, label, hint, error, affix, and pass-through options. Host-provided autocomplete value such as `current-password`.
Not included Password visibility toggle. Password strength meter. Credential policy, storage, authentication flow, or browser password-manager rules.

Use this companion artifact when a review needs password-specific native wrapper evidence. Use `native_field_visual_reference.html` for the broader native helper family and `password_field.md` for the source-of-truth responsibility boundary.

Desktop and narrow viewport checks should confirm labels, hints, error copy, and affix text wrap without overlap. Do not treat this static HTML as production CSS or runtime behavior. Do not add password visibility, strength, validation policy, authentication, or credential-storage expectations to Rails Fields Kit from this artifact.
