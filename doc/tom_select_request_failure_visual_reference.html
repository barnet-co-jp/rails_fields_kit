Review checklist

  • Confirm hidden, revealed, restore-failure, create-failure, and custom-wrapper states stay readable on desktop and narrow viewports.
  • Confirm operation and status metadata labels wrap without relying on color alone.
  • When the same object/method appears more than once, confirm explicit ids keep `aria-describedby`, placeholder id, and `detail.surface` aligned per instance.
  • Keep `load-error`, `selected-load-error`, and `create-error` as host-app hooks rather than full lifecycle simulations.
  • Do not add default visible error copy, built-in retry UI, request behavior, or production helper markup from this artifact.

Scope note. This page is a static visual aid. The maintained contract for `error_surface: true`, `error_surface_html:`, duplicate object/method id handling, and Tom Select-backed request-failure hooks remains in the helper docs and runtime code.
