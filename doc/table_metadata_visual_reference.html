Boundary

What this visual reference does and does not claim

Keeps the quick visual entrypoint aligned with the maintained metadata contract instead of turning it into an API proposal.

Rails Fields Kit owns rendering assistance. Metadata objects, renderer mapping, and the current FormBuilder helper families are the supported surface shown here.
The host app or table integration owns behavior. Query execution, token parsing, persistence, authorization, result rendering, and shared source registries remain outside this static reference.

Keep responsibility boundaries explicit so a visual docs page does not imply a broader runtime contract than `table_adapters.md`, `shared_metadata_navigation.md`, and `public_api.md` already document.

Scope note. This page is a static visual aid for representative table metadata lanes. The maintained protocol for `TableFilterInput`, `TableCellInput`, `TableMetadata`, `TableRenderer`, `group_html:`, and helper responsibility boundaries remains in the README and table adapter docs.
