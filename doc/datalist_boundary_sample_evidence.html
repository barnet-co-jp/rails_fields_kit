Review boundaries

Rails Fields Kit owns

Native wrapper wiring for the text input and the existing Tom Select-backed helper families.

Host app owns

Datalist options, authorization, candidate scoping, submitted-value interpretation, and any custom copy.

Browser owns

Datalist popup display, filtering feel, keyboard behavior, and platform-specific styling limits.
