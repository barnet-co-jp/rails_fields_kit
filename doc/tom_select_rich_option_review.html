Review focus

  • Check that label, description, and badge can coexist without clipping at desktop and narrow widths.
  • Compare long label and long description cases before changing production CSS or helper markup.
  • Keep endpoint payload shape, option mapping, search execution, and authorization in topic docs and host-app code.

Scope boundary

This page is a static companion to the Tom Select core reference. It does not change helper markup, Tom Select renderer behavior, production CSS, endpoint payload contracts, search execution, or authorization.

  • Use `controller_helpers.md` for rich option field configuration.
  • Use `public_api.md#javascript-exports` for current package-root helper surfaces.
  • Use PR comments or sample app evidence logs for browser-rendered evidence when this artifact changes.
